README-Editor und UI-Bereinigung

- Unpassende, fallbezogene Erklaerung unter der Auswahl zur Remote-Historie entfernt.
- Technischer Sicherheitshinweis am unteren Fensterrand entfernt.
- Neutraler kurzer Hinweis beibehalten: Auswahl des Umgangs mit einem abweichenden Remote-Stand.
- Optionaler Button README oeffnen ergaenzt.
- Vorhandene README.md wird automatisch geladen.
- Falls keine README.md vorhanden ist, kann eine neue README.md angelegt werden.
- Bearbeiten-Modus fuer Markdown.
- Vorschau-Modus mit einer GitHub-aehnlichen, lesbaren Darstellung fuer Ueberschriften, Listen und Codebloecke.
- Speichern schreibt die README direkt in den ausgewaehlten Projektordner.
- Ungespeicherte Aenderungen werden beim Schliessen abgefragt.
- README-Datei wird beim anschliessenden Push automatisch durch git add -A beruecksichtigt.
